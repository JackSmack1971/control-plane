# Roadmap

## 1. Contract bootstrap

Establish the repository layout, governing instructions, and trust invariants. No runtime behavior is introduced in this stage.

## 2. Manifest and deterministic validation

Define the manifest schema as the policy source of truth and add deterministic validation for declared artifacts and write sets.

## 3. Evidence and independent verification

Add read-only verification, evidence capture, and rejection or rollback handling.

## 4. Generated policy lifecycle

Generate read-only policy artifacts from the manifest, with a controlled update path and no manual edits.
